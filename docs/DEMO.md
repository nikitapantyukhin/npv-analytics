# Сценарий защиты

1. `docker compose up --build -d`; проверить `/api/health` и экран подключений.
2. В генераторе создать mixed-портфель на 1000 сделок с seed 42. Показать exact counts и сохранённый hash.
3. Открыть реестр и карточку сделки; показать исходные 48/49 полей и знак депозита.
4. Загрузить проверенный `CBKEY1M` CSV, если в портфеле есть FLOAT.
5. Нажать расчёт: реальный pinned `cfgen` создаёт события и исходные ошибки. Если часть сделок отклонена, показать `partial`, а не общий NPV.
6. Запустить QuantumTeam отдельно и получить live snapshot. Offline fallback допустим только для ранее сохранённого `quantum_cached`; учебный набор импортируется как `educational_reference`.
7. Выбрать снимок и получить полный NPV по показанной методике.
8. В факторном анализе применить +100 б.п. к discount curve. Показать неизменные CF, новый DF/PV, ΔNPV и телескопический waterfall.
9. Открыть runs/logs: SHA, hash, стадии, ошибки и источник.
10. Открыть historical mode: при отсутствии двух снимков показать конкретный список недостающих данных.

Если QuantumTeam недоступен, защита продолжает генерацию и `cfgen`; NPV демонстрируется только на сохранённом проверенном snapshot либо явно учебном эталоне. Частичный CF никогда не выдаётся за NPV полного портфеля.
