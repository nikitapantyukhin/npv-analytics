# Финансовая методика PV / NPV

Версия: `NPV-CONTINUOUS-ZERO-ACT365-v1`. Статус: рабочая, проверяемая, но continuous-zero трактовка внешней `rate` требует подтверждения методологом.

## Знаки и формула

Для сделки `j` остаток `B_j` берётся со знаком контракта: кредит `> 0`, депозит `< 0`. Все будущие события `CF_j,i` берутся из `cashflow.csv` со знаком; технические нулевые repricing-события сохраняются, но PV не меняют.

```text
PV_j = Σ CF_j,i × DF(t_i)
NPV_j = PV_j − B_j
NPV_portfolio = Σ NPV_j
ΔNPV = NPV_scenario − NPV_base
```

Начальная выдача повторно не добавляется. Потоки `client` и `sub` остаются различимыми. Если нет DF хотя бы для одного ненулевого CF, полный NPV не создаётся.

## Дисконтирование

```text
t = (payment_date − valuation_date) / 365
DF(t) = exp(−r(t) × t)
PV_i = CF_i × DF(t)
```

`r` хранится как decimal. Между узлами линейно интерполируется zero rate. До первого и после последнего узла скрытая экстраполяция запрещена. Сценарный параллельный сдвиг `bp/10000` добавляется к zero rate, после чего DF вычисляется заново. Денежные CF при таком сценарии не меняются и `cfgen` повторно не вызывается.

## Точность

Деньги и ставки аккумулируются `Decimal` с precision 34. Округление до копеек применяется на границе отображения/экспорта, не внутри суммы PV. События суммируются отдельно; предварительный неттинг способен отличаться на последний знак Decimal и не используется. Процентное изменение определяется как `ΔNPV / |NPV_base|`; при нулевой базе результат не определяется.

## Факторная атрибуция

Факторы применяются в отображаемом порядке. Вклад шага `i`: `V_i − V_(i−1)`. Автотест проверяет телескопическую сумму. Изменение договорной ставки должно создавать новую сценарную сделку и отдельный запуск `cfgen`; текущий UI честно блокирует этот фактор до выбора соответствующей фоновой операции.

## Excel

Контроль `PV=2 056 999,50`, `B=3 646 037,89`, `NPV=−1 589 038,39` применим только к идентичным CF/DF из Excel спринта 2. Код не подгоняет произвольные графики под это число. Точная regression-фикстура старого Excel в переданных материалах отсутствует; формула и signed credit/deposit проверены unit-тестами.
