# NPV Analytics — визуальный комплект для Codex

В комплекте **15 отдельных PNG**, точная статическая HTML/CSS-основа, дизайн-спецификация и инструкция для Codex.

## Использование

1. Распакуйте архив **в корень проекта**. Он создаёт `.local/designs/`.
2. В задании Codex укажите: «Посмотри `.local/designs/CODEX_INSTRUCTIONS.md` и `.local/designs/DESIGN_SPEC.md`, затем все изображения в `.local/designs/screens/`. Это канонический дизайн».
3. Исходный HTML/CSS лежит в `.local/designs/source/`. Это не готовое приложение: содержимое экранов статическое.
4. Референсы GuardPro и Command Center лежат в `reference/` только как стилевое вдохновение. Источник истинных размеров — `screens/` и `source/`.

**Важно:** все финансовые показатели на макетах иллюстративные. В будущем приложении реальные данные должны поступать из backend.
